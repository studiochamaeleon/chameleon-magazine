# CHAMELEON MAGAZINE Studio

Sanity Studio for writing, editing, and publishing CHAMELEON MAGAZINE articles.

```sh
npm install
npm run dev
```

Project:

- Project ID: `a5gektp6`
- Dataset: `production`

Deploying the Studio with `npm run deploy` publishes a separate Sanity Studio URL. Do that only when you are ready to use the Studio outside local development.
